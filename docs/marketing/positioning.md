# Ashlar Marketing Positioning

## Product Truth

### Name & One-liner
- **Product name:** Ashlar
- **One-liner:** Local-first .NET runtime for auditable AI workflows you embed

### Everyday Framing
Use this language to communicate what Ashlar does to non-technical audiences:
- **"Receipts for AI actions"** — every task has an audit trail
- **"Bouncer for new skills"** — certification gate controls what code runs

### Precision Line
Technical / developer-facing positioning:
- **Trust log** — audit trail for every execution
- **Cert-gate** — analyzer fence → witness → mutation testing → determinism

## Is / Is Not

### Ashlar IS:
- **Local-first:** Self-hosted .NET runtime you embed or run
- **Auditable:** Trust log records every task, every proposal
- **Certified:** Code proposals pass gates before admission
- **Embeddable:** NuGet packages, HTTP API, CLI, or source integration
- **Open core:** Single-node runtime Apache 2.0

### Ashlar IS NOT:
- ❌ A hosted SaaS or chatbot
- ❌ Cloud-dependent (cloud providers are opt-in targets, not requirements)
- ❌ A drop-in IDE plugin by itself
- ❌ Autonomy-ready for production unattended use (HOLD until dogfood scorecard + dated Strict E2E + real hygiene PR)

## What's Live vs. Roadmap

### ✅ Live (Community / Apache 2.0)
- Runtime & orchestration
- Trust log & audit trails
- Certification gate (CI-proven, required check on master)
- Local-first model routing (Ollama)
- NuGet packages, HTTP API, CLI, containers
- Shared automations + multi-node mesh (federation)

### 🚧 Roadmap / Waitlist Only
- **Ashlar Cloud (PAYG):** Not live; waitlist only — never imply GA
- **Autonomy / self-extend:** Design-partner marketing HOLD until dogfood scorecard + dated Strict E2E + real hygiene PR
- **Production autonomy:** In-process loop ships sealed (hold mode by default)

## Funnel Stages

### Aware → Interested
- **Message:** "Receipts for AI actions" + "Bouncer for new skills"
- **Channels:** GitHub README, landing page, social cards, technical blog posts
- **CTA:** Start with TesterQuickstart (clone, build, run API, submit task, read audit trail)

### Interested → Trying
- **Message:** "Build trustworthy AI applications on infrastructure you control"
- **Channels:** Docs (TesterQuickstart, IntegratorGuide), demo videos
- **CTA:** Follow quickstart (15 minutes, no Docker, no API keys)

### Trying → Adopting
- **Message:** "Embed Ashlar in your application via NuGet, HTTP client, or CLI"
- **Channels:** IntegratorGuide, SDK docs, compose stacks
- **CTA:** Embed runtime via `services.AddAshlar()`

### Adopting → Paid
- **Message:** "Community free forever. Builder/Team/Enterprise for scale and sovereignty."
- **Channels:** Pricing page, commercial discussions
- **CTA:** Contact for Builder/Team/Enterprise (starting ~$8k/yr)
