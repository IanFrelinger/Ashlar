## 15-second version

Ashlar isn't a chat box. It's a **control layer** that turns AI know-how into **verified behavior** — with **receipts** for what ran, and a **bouncer** so new **plugins/recipes** get **checked before they run**. You can move that behavior between systems and still stay in control.

## 30-second version

Most AI tools are a chat window. Ashlar is for builders who put AI inside their own product: ideas get **proposed**, Ashlar's **gate** decides what's admitted, that becomes a **portable package**, each host **re-checks the contract**, and you get a **receipt**. Same idea as a JVM — but for **behavior**, not code bytecode hype. Local-first. The AI can suggest; the company keeps the keys.

**Design partner:** pick **one behavior**, run it through the gate, package it, keep the receipts — about **~$4k / 90 days**.
