# Ashlar claims cheat sheet (Sales / Social)
**Status:** Product lock · 2026-09-19  
**Owner:** Marketing/Product 3000  
**Audience:** Ashlar Sales Rep, Ashlar Social, CEO decks  
**Center:** Ashlar governs behavior, not intelligence.

One page. If a claim isn't here, don't invent it.

---

## ALWAYS (say freely)

- **Governs behavior, not intelligence** — verified, constrained behaviors you can audit and reuse  
- **Not a chat box** — control layer under AI in *their* software  
- **Receipts + bouncer** (audit trail + checked before it runs)  
- **Authority outside the agent** — propose ≠ admit; gates/operator decide  
- **Portable packages** — admit once, hosts **re-check the contract**, leave a receipt  
- **Surfaces:** NuGet, CLI, HTTP API, containers · local-first / self-host  
- **Community free** · **Design partner** on the **live** path (one behavior → gate → package → receipts)  
- **Support:** Discord + GitHub Discussions  

**One-liner:** Ashlar turns AI-generated know-how into verified, reusable behavior you can audit, move between systems, and run under constraints.

Everyday Joe: *plugin/recipe* + *checked before it runs* / *passed the safety check* — not skill/certified (diploma vibe).

---

## SOFT (true, don't lead / don't oversell)

- Mesh / share + re-verify primitives exist — **not** Fleet org plane as sold SKU; **not** headline  
- Builder ~$8k / Team ~$25k / Enterprise from ~$75k — indicative until order form  
- Cloud PAYG — **waitlist only**  
- Human-governed self-extend — sealed/hold by default (not unattended GA)  
- **Prompt certification (vision):** prompt packs verified for **same required behavior** across approved models (witness/tests) — not byte-identical output; swap models safely when proven  
- Learning Harness — architecture / principle; **not** shipped GTM unlock  
- Protocols (MCP/A2A/gRPC), adapters, orchestration mechanics — supported, **not headline**
