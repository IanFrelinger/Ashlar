# Ashlar claims cheat sheet

**Audience:** Sales, Social, anyone posting or pitching.  
**Owner:** Marketing/Product.  
**Status:** Product-locked 2026-09-19. Autonomy marketing HOLD until Dogfood unlock.

## Always claim (live)
- Local-first .NET runtime for auditable AI workflows you embed
- Receipts for AI actions (trust log) + bouncer for new skills (cert-gate)
- Authority stays outside the agent — propose ≠ promote; gates/operator decide trust
- Self-host / NuGet / CLI / API — data on infrastructure you control
- Community OSS free forever; design partners on the **live** product only
- Support: Discord + GitHub Discussions

## Soft claim (ok with honesty)
- Shared automations + multi-node **mesh primitives** exist (federation) — not Fleet org plane as a sold SKU
- Builder / Team / Enterprise pricing is **indicative** — lead with design partner (~$4k / 90 days) first
- Ashlar Cloud PAYG is **waitlist / coming soon** — never "live" or "GA"

## Never claim (HOLD)
- Production autonomy / unattended self-extend / "agents that improve themselves"
- Learning Harness as a **shipped product** (architecture + M7 roadmap only)
- Ashlar Cloud available / PAYG live
- Forge GA as a sold product
- Fleet org plane / SSO as table-stakes today
- Dogfood unlock implied by CI artifacts alone (artifacts ≠ landed Strict PASS rows on master)
- lim-7/8/9 CLOSED ≠ autonomy marketing unlock

## Dogfood unlock gates (Learn / autonomy — cite scorecard verbatim)
Until all are met, Learn/autonomy stay HOLD:
1. Last-N=10 ≥80%; mean time-to-admit ≤15m; Strict rejection ≤70%; ≥7 consecutive days (see `docs/dogfood-scorecard.md`)
2. ≥7 **landed** dated Strict PASS rows on master in `docs/dogfood-ledger.md` (not artifacts alone)
3. Hygiene-via-Ashlar PR (real loop PR, not fixture-only)

## Public verbs
**Run · Prove · Control · Share** — not Learn (until unlock).
