# Marketing Landing Page

A professional commercial marketing landing page for Ashlar is available at [`site/index.html`](../site/).

## Quick Links

- **Live site:** Enable GitHub Pages → `/site` folder to host at `https://ianfrelinger.github.io/Ashlar/`
- **Local preview:** `cd site && python3 -m http.server 8000`

## Design

Clean, modern developer-tool aesthetic (Linear/Vercel/Notion-adjacent):
- Bento-grid asymmetric feature sections
- Large typography, high contrast, intentional whitespace
- Official brand assets only (no AI-generated collage imagery)
- Transparent pricing comparison table

## Key Sections

1. Hero — "The .NET runtime you build AI products on"
2. Bento Grid — Auditable workflows, certification gate, your infrastructure, build integration, terminal preview
3. Pricing Table — Community (free), Pro ($1,500/yr), Team ($12,000/yr), Enterprise (from $40,000/yr, partner-led); Design Partner and Cloud waitlist in the footnote
4. CTA — GitHub start + email contact

## Messaging Alignment

- Embeddable .NET runtime (NuGet dependency)
- Audit + certification guarantees
- Local-first with optional cloud
- Open-core → commercial model
- No false product claims (Cloud marked "coming soon / design partners")
