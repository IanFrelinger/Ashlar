# Experimental Marketing Assets (Archive)

This directory contains AI-generated marketing assets that were explored but **not used** on the landing page. They are kept here for reference only.

## Archived Assets

These assets feature collage/seal/tape/doodle/3D aesthetics that don't align with the clean, modern developer-tool aesthetic (Linear/Vercel/Notion-adjacent) we're targeting:

- `ashlar-og-commercial-1280x720.png` — AI-generated OG card with collage/seal styling
- `ashlar-landing-hero-1600x900.png` — AI-generated hero reference with faux masonry/tape
- `ashlar-linkedin-launch-1080.png` — AI-generated LinkedIn asset with decorative elements

## Why Not Used

Stakeholder feedback: these feel like "AI slop" with:
- Collage aesthetics (masking tape, gold wax seals, sparkles)
- Handwritten doodles and annotations
- Faux 3D stone/masonry heroes
- Cinematic lighting and hyper-detail
- Too much decorative gold (brand guideline: gold = certified only, sparse)

The landing page instead uses:
- Official brand SVGs (`ashlar-logo-flat.svg`, and `ashlar-icon-github-clean.svg` as the favicon)
- Flat, typographic OG card generated from HTML/CSS
- Clean bento-grid layout with real code snippets
- Modern developer-tool aesthetic (2026 standard)

## For Future Reference

When creating new marketing assets:
- **Do:** Clean typography, high contrast, official brand SVGs, minimal flat design
- **Don't:** Collage, masking tape, doodles, seals, sparkles, faux 3D, AI illustration aesthetics

See `../BRAND.md` for official brand guidelines.
